# 2026-2050 Transition: Collapse & Realignment

**Type:** `= this.type`
**Status:** `= this.status`

This document traces the causal arc from the present day through the end of 2049 — the most transformative quarter-century since 1945-1970. It covers the dissolution of US federal authority, the emergence of successor states, climate-driven transformation, technological disruption, economic reconfiguration, demographic shifts, and cultural realignment across six STEEP domains. It describes *how* the world gets to 2050; the 2050 steady-state snapshot belongs to Phase 3.

## Document Structure

This document uses a two-part hybrid structure:

- **Timeline:** A chronological table of 14 inflection events (T-01 through T-14) that define the causal arc. Each event has a machine-readable ID used for cross-referencing by all downstream sections.
- **Domains:** Six domain sections analyzing drivers and trajectories within each STEEP domain, with each key event linked back to the timeline by its T-ID.
- **Cross-Domain Synthesis:** A dedicated section mapping feedback loops across domain pairs, placed after all six domain sections.
