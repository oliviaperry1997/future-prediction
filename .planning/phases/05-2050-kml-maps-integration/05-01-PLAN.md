    1. **Polygon merging** — Use shapely `unary_union` to merge county polygons for each entity. For entities spanning state lines (PPR = CA+OR+WA+Clark NV), merge all matching counties.
    2. **Douglas-Peucker** — Use `shapely.simplify(tolerance=0.02)` for ~2km vertex spacing (~0.02 deg ≈ 2.2km at mid-latitudes). Per D-16, target 5-20km. Adjust tolerance to ~0.01-0.02 for the best result.
    3. **Folder hierarchy** — Build KML Folder elements per entity-config.json hierarchy (Continent > Subregion > Entity). Per D-02/D-15.
    4. **CascadingStyle + StyleMap** — Copy the StyleMap pattern from Earth Current.kml. Use `gx:CascadingStyle` with `<Style>` children containing `<LineStyle>`, `<PolyStyle>`, `<BalloonStyle>`.
