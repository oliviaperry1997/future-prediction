## Decisions Made

- **Source data choice:** Used Natural Earth 1:110m countries (GeoJSON → ogr2ogr KML) instead of failed geoBoundaries GPKG download. The 110m resolution lacks microstates but covers all major global powers. User can upgrade to 50m or 10m for more detail.
- **County data format:** Census TIGER/Line KML uses STUSPS (state abbreviation) and STATEFP (FIPS code) in ExtendedData/SimpleData elements. Script reads STUSPS for state matching against entity-config.json state abbreviations.
- **Demographics/Culture KMLs:** These domains only have entity-level See KML markers (referencing entities in borders.kml), so their KML files contain empty top-level folders. The markers will resolve to borders.kml polygons when viewed in Google Earth.
- **Style convention:** 5 distinct style types (default, indigenous, reactionary, fragmented, modification) with CascadingStyle + StyleMap per Earth Current.kml conventions. Colors follow Google Earth ABGR format.

## Deviations from Plan

None — plan executed as written. The script generates both the config/data and all 6 output KML files in a single run, which the plan described across two tasks.

## Issues Encountered

1. **GeoBoundaries GPKG download failed** — The GitHub raw URL returned an HTML page instead of a GPKG file. Switched to Natural Earth 1:110m countries in GeoJSON format, converted via ogr2ogr.
2. **County KML parsing required format adjustment** — Census TIGER/Line uses ExtendedData/SimpleData rather than name-field conventions. Updated `read_county_kml` to read STUSPS and STATEFP from SimpleData elements.
3. **Global KML code extraction** — Natural Earth uses ADM0_A3 field name in SimpleData. Updated `read_global_kml` to read this field.
4. **Folder hierarchy nesting** — Config has variable-depth nesting (Continent > Subregion > Category > Entity for US, Continent > Entity for global). Replaced flat iteration with recursive `build_hierarchy_folders` that handles both dict and list node types.
5. **Namespace declaration** — lxml doesn't support setting `xmlns:gx` as an XML attribute; switched to passing via `nsmap` parameter.

## Threat Flags

None — this plan creates no new network endpoints, auth paths, or file access patterns. Source data is public Census/natural earth data. Cross-reference paths in KML descriptions use relative file paths only.

## Known Stubs

- **Global microstates** (PSE, GUM, SGP, 15 Caribbean/Pacific island codes) — Not in Natural Earth 1:110m data. Entity folders exist but are empty. Will need either higher-resolution source data or manual polygon drawing in Google Earth Pro.
- **Rough overlay polygons** (climate, technology, economy) — All 32 overlay placemarks use coarse bounding polygons. Per D-04 and D-19, these are placeholders for user refinement in Google Earth Pro.
