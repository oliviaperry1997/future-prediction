  <name>Task 2: Create data download script and acquire source datasets</name>
  <files>2050-snapshot/kml/source/download-data.py</files>
  <action>
    Create `download-data.py` in `2050-snapshot/kml/source/` that:
    1. Checks and installs required Python packages: `rasterio`, `fiona`, `shapely`, `simplekml`, `pyproj` (all via pip)
    2. Defines download functions for each data source:
       - `download_koppen(output_dir)` — Downloads GloH2O V3 GeoTIFF for 2041-2070 SSP3-7.0 from figshare. Use the DOI URL pattern. Target file: `koppen_2041-2070_ssp370.tif`
       - `download_biomes(output_dir)` — Downloads WWF Terrestrial Ecoregions shapefile (or provides instructions + URLs for manual download since WWF site may require browser interaction)
       - `download_watersheds(output_dir)` — Downloads HydroSHEDS HydroBASINS v1c for relevant continents (Africa, Asia, Europe, North America, South America, Australia/Oceania) at Pfafstetter level 4-5 from hydrosheds.org
       - `download_dem_tiles(output_dir)` — Downloads SRTM 30m or Copernicus DEM 30m tiles for the 6 SLR inundation regions (Bangladesh, Mekong, Nile, US Gulf, Pacific atolls, Netherlands)
    3. Each function should:
       - Check if target file already exists (skip if present)
       - Log download progress
       - Verify file integrity (file size > 0, format check)
       - Return path to downloaded file
    4. Main script accepts optional `--all` flag to download everything, or individual flags per dataset
    
    For datasets that require browser interaction (some WWF/HydroSHEDS downloads use click-to-accept):
    - Print exact download URL and instructions
    - Provide a `--manual` mode that waits for user confirmation after manual download
    
    Use urllib/requests for HTTP downloads. Handle redirects. Set reasonable timeouts (300s per file).
  </action>
