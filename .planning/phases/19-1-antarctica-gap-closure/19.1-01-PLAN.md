**Step A: Write a Python script for longitudinal sector clipping.**

The current approach in Phase 19 used point-in-polygon assignment (each existing GADM polygon patch assigned to a zone based on centroid longitude). Replace with true sector clipping:

1. Parse all existing Antarctica polygon coordinates from the current borders.kml
2. For each polygon's coordinate ring, split at sector boundaries (meridian lines at 20°W, 45°E, 53°W, 90°W, 136°E, 142°E, 150°W, 160°E)
3. This requires polygon clipping algorithms — for each polygon that crosses a sector boundary:
   - Find intersection points along the meridian
   - Split the polygon into two fragments (one on each side of the boundary)
   - Assign each fragment to the correct zone by its centroid
4. But for simplicity and reliability, implement as: iterate through all coordinates in each polygon, assigning each coordinate to a zone based on its longitude, and create linear-ring fragments per continuous zone segment within the polygon. Where a polygon crosses a sector boundary, create two Placemark fragments.
5. Each claim-zone folder gets its Placemarks with the appropriate styleUrl
